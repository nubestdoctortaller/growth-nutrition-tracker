# Weekly Growth Nutrition Tracker for Kids and Teens

A simple, single-page tracker that helps parents keep an eye on five everyday food habits that support healthy growth in kids and teens: protein at every meal, calcium foods, vitamin C produce, fish twice a week, and iron and zinc foods.

Parents tap each day as a habit happens. Progress is saved in the browser on that device and clears automatically at the start of each new week (Monday).

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page content and tracker layout |
| `style.css` | Styling (Doctor Taller brand greens, Poppins font) |
| `script.js` | Tracker logic and weekly local storage |
| `README.md` | This file |

## Publish with GitHub Pages

1. Create a new public repository and upload all four files to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then click **Save**.
4. After a minute or two, the site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Editing the habits

The habits, their labels, and weekly targets are defined in the `HABITS` array at the top of `script.js`. Matching explanations are in the "Why these five habits" section of `index.html`.
